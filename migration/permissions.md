# FND Permission Model

## Roles

- developer
- manager
- admin
- smt
- staff

## Developer

- Full system access
- Full settings access
- Full user management
- Full module access

## Manager

- Full view access
- Full edit access
- Staff management
- Leave approval
- Overtime approval

## Admin

- Same access as Manager

## SMT

- View all modules
- Edit own department
- Additional access via special permissions

## Staff

- Submit Leave Requests
- Submit OT Requests
- Limited viewing access

## Additional Permissions

- isIncharge
- tempDeptAccess
- tempDeptTarget

- rampsheetEditAccess
- rwyLightEditAccess
- birdCountEditAccess
- opsBoardAccess
